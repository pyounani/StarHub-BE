## STARHUB

`#위치 기반 모임 서비스` `#편리한 정보 제공` `#안전한 개인정보 관리` <br /> <br />
지도 기반으로 모임을 쉽게 찾고 안전하게 참여할 수 있도록 지원하는 웹 서비스, STARHUB입니다. <br />

_written by pyounani_


### 소개
기존 모임 서비스들은 장소, 기간, 시간 등의 필수 정보가 충분하지 않아 사용자에게 불편을 주고 개인정보가 노출될 우려가 있었습니다. 
STARHUB는 모임의 정확한 위치를 지도에 표시하고, 개인정보를 보호하면서 편리하게 모임에 참여할 수 있도록 돕습니다.

### 기술 스택 및 아키텍처 설계도


### 핵심 기능
- 회원 관리: 회원가입, 로그인, 프로필 생성, 익명사용자 관리
- 마이페이지: 내가 작성한/좋아요 누른/참여한 모임 조회
- 모임 기능: 모임 개설, 수정, 삭제 및 목록 조회
- 모임 검색 기능
- 지원서 관리: 지원서 작성 및 스터디원 확정
- 좋아요 및 기술 스택 관리
- 인기글 조회 (Redis 캐싱 적용)
